# Revisiting Privacy-Preserving Mammography Classification with Conditional Diffusion

Research code and verified aggregate results for a MIDL 2027 manuscript. Citation details will be added after review
(see [Citation](#citation)).

This study revisits **Osuala et al. (2024)**, *Enhancing the Utility of Privacy-Preserving Cancer Classification
using Synthetic Data* ([code](https://github.com/RichardObi/mammo_dp), [arXiv:2407.12669](https://arxiv.org/abs/2407.12669)).
They trained a mass classifier on CBIS-DDSM patches with differentially private SGD (DP-SGD). They showed that adding
synthetic patches from a conditional GAN (MCGAN) to the DP training set improves utility at a fixed privacy budget.

We reproduce their Real-only DP protocol. We then replace the GAN with **CC-NET**, a class-conditional latent diffusion
model, and add a control for an optimisation confound that adding synthetic records introduces.

## What was done

All classifiers share one protocol, matching the public mammo_dp classifier code:

| Setting | Value |
|---|---|
| Model | Swin-T with a frozen ImageNet backbone and the reference two-layer head 768 → 384 → 2 (296,066 trainable parameters) |
| DP-SGD | Opacus 1.5.4, Poisson sampling, clipping norm 1.0, δ = 10⁻⁴, RDP accountant, 300 epochs |
| Checkpoint selection | Best validation AUPRC (benign as positive) within ε ∈ [0.75, 1.05]·ε_target |
| Validation set | Official patient-disjoint 192 images |
| Seeds | 42, 43, 44 |

| Condition | Training records | Batch | Sample rate q | ε | Runs |
|---|---|---|---|---|---|
| **A. Real-only DP** (reproduction baseline) | 1,104 real CBIS-DDSM patches | 128 | 1/9 | 1, 6, 60 | 9 |
| **B. Real+CC-NET DP** | 1,104 real + 3,000 CC-NET (1,500 benign / 1,500 malignant), one DP mechanism | 128 | 1/33 | 1, 6, 60 | 9 |
| **C. M1 optimisation control** | 1,104 real | 34 | 1/33 | 6 | 3 |

**Why M1 exists.** Adding 3,000 records changes the DP-SGD mechanics: B has a smaller q, a smaller noise multiplier σ
(2.34 vs 4.34 at ε = 6) and 3.7× more optimiser steps. M1 is Real-only training with exactly B's q, σ and step count.
- It is an **additional control**, not a replacement for the Osuala-protocol baseline A.
- It does **not** isolate the diagnostic content of the synthetic images (see [docs/limitations.md](docs/limitations.md)).

**Test sets.** All models are evaluated on the held-out CBIS-DDSM test set (402 patches, 212 patients) and the external
BCDR test set (1,106 patches).

**Image quality.** The image-quality comparison uses ImageNet FID and FRDv1 between CC-NET, the published MCGAN images
and real patches.

## Verified findings

Values are mean ± sample SD over 3 independently trained seeds, malignant-positive AUROC. Full results, both AUPRC
directions, confidence intervals and per-seed values are in [`results/verified_summary/`](results/verified_summary).

| ε | CBIS-DDSM: Real-only | CBIS-DDSM: Real+CC-NET | BCDR: Real-only | BCDR: Real+CC-NET |
|---|---|---|---|---|
| 1 | 0.525 ± 0.076 | 0.586 ± 0.051 | 0.494 ± 0.010 | 0.565 ± 0.013 |
| 6 | 0.571 ± 0.059 | 0.620 ± 0.018 | 0.539 ± 0.014 | 0.631 ± 0.009 |
| 60 | 0.604 ± 0.029 | 0.630 ± 0.000* | 0.596 ± 0.018 | 0.654 ± 0.003 |

\*SD 0.0002; the three seeds are distinct models.

**Main results**
- **BCDR (external).** Adding CC-NET images improved AUROC at every ε in all 9 seed pairs: Δ = +0.070 / +0.091 / +0.058
  at ε = 1 / 6 / 60.
- **CBIS-DDSM (in-domain).** The mean gain is positive (+0.062 / +0.049 / +0.027), but it is **not consistent across
  seeds** at ε = 6 and 60 (2/3 seeds positive). At ε = 60 the bootstrap CI includes zero.
- **Reproduction.** All six Real-only cells agree with Osuala et al.'s reported values within one SD
  ([Table S1](results/publication_tables/tableS1_osuala_comparison.tex)).

**M1 control (ε = 6)**
- M1 alone raises Real-only AUROC by +0.022 (CBIS) and +0.029 (BCDR).
- Under matched mechanics, adding CC-NET records still improves BCDR AUROC by **+0.062** (3/3 seeds; bootstrap CI
  [+0.037, +0.085]). The CBIS-DDSM residual (+0.027, 2/3 seeds) is unresolved.

**Image quality**

| Generator | ImageNet FID | FRDv1 |
|---|---|---|
| CC-NET | 66.0 ± 3.0 | 7.24 ± 0.84 |
| MCGAN | 94.0 ± 2.4 | 7.73 ± 0.71 |

- The real-vs-real reference FID is about 25.
- The FRDv1 subsampling intervals overlap, so that difference is not conclusive.

**What these results do not show.** We do **not** claim:
- that CC-NET gives better downstream classification than MCGAN. The matched Real+MCGAN DP experiment was not run,
  because the published MCGAN images' generator provenance is unresolved.
- end-to-end differential privacy;
- that diagnostic image content causes the gain.

## Installation

```bash
git clone <repository-url> && cd mammography-diffusion-dp
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # exact versions used for the reported runs (torch 2.5.1, opacus 1.5.4)
pip install -e ".[dev]"           # add [generation] for CC-NET, [quality] for FID / FRDv1
pytest                            # CPU only, no medical data, about 1-2 minutes
```

Training needs a CUDA GPU; each run took about 15–50 minutes on one NVIDIA L40S. The tests, privacy calibration,
statistics, tables and figures run on CPU.

## Data

Obtain the data from its official sources. **No images are distributed here.** See [docs/datasets.md](docs/datasets.md).

- **CBIS-DDSM and BCDR patches.** Use the patch dataset of Osuala et al. (`dataset16062024/` in mammo_dp), derived
  from CBIS-DDSM (TCIA) and BCDR (available on request from the BCDR team). Our split files are byte-identical to that
  folder.
- **MCGAN images.** These are only needed for the image-quality comparison. Use mammo_dp
  `extension/synthetic_data/cbis-ddsm/c-dcgan/`.
- **CC-NET synthetic pool.** It is not distributed (see [docs/limitations.md](docs/limitations.md)).

```bash
cp .env.example .env && set -a && source .env && set +a       # set MDPD_* paths
python scripts/prepare_data.py validate --data_root $MDPD_DATA_ROOT --synthetic_dir $MDPD_SYNTHETIC_DIR
python scripts/prepare_data.py build-folders                  # real_train (1,104) and realsyn_train (4,104)
```

## Running the experiments

```bash
# print the exact training + evaluation commands (add --execute to run them)
python scripts/run_experiment.py --condition real_only  --epsilon 6 --all-seeds
python scripts/run_experiment.py --condition real_ccnet --epsilon 6 --all-seeds
python scripts/run_experiment.py --condition m1_matched --epsilon 6 --all-seeds

python scripts/calculate_privacy.py calibrate                  # sigma, q, steps, epsilon for every condition (CPU)
python scripts/compute_statistics.py --runs runs.csv --contrast real_ccnet:real_only --out_dir stats/
python scripts/reproduce_tables.py && python scripts/reproduce_figures.py
```

For CC-NET training and generation, and for FID / FRDv1, see [docs/experiments.md](docs/experiments.md).

## Privacy scope

- **What ε covers.** ε bounds the DP-SGD training of the classifier head, at the **image level**, with synthetic
  images counted as records of the same mechanism.
- **What it does not cover:**
  - the CC-NET generator, which was trained without DP on CBIS-DDSM training images;
  - checkpoint selection on the validation set;
  - patient-level adjacency (patients contribute up to 14 images).
- **Synthetic images are not anonymous.** They come from a non-private generator trained on patient images and should
  not be treated as anonymous or free of privacy risk.

See [docs/privacy.md](docs/privacy.md).
