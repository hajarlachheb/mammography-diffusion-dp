# Datasets

This repository contains **no images**: no real mammograms, patches, or synthetic images. Obtain every dataset from its
official source and accept its terms.

## Patch dataset used for every classifier (CBIS-DDSM + BCDR)

We use the processed mass-patch dataset of Osuala et al. (2024), folder `dataset16062024/` of
[RichardObi/mammo_dp](https://github.com/RichardObi/mammo_dp). Our split files are byte-identical to that folder.

| Split | Path under the data root | Images | Malignant / benign | Patients |
|---|---|---|---|---|
| CBIS-DDSM train | `cbis-ddsm/train` | 1,104 | 525 / 579 | 578 |
| CBIS-DDSM validation (official, patient-disjoint) | `cbis-ddsm/val` | 192 | 102 / 90 | 102 |
| CBIS-DDSM test | `cbis-ddsm/test` | 402 | 157 / 245 | 212 |
| BCDR test (external) | `bcdr/test` | 1,106 | 486 / 620 | 394 (filename-derived; see below) |

**Folder layout.** Each split has the folders `is_benign_false/` (malignant, ImageFolder class 0) and `is_benign_true/`
(benign, class 1).

**What `prepare_data.py validate` checks:**
- these counts;
- that each file sits in the folder matching its label;
- zero patient overlap between CBIS train, validation and test;
- zero exact-duplicate overlap (SHA-256) between all four splits.

**Original sources:**
- **CBIS-DDSM:** The Cancer Imaging Archive (TCIA), Curated Breast Imaging Subset of DDSM.
- **BCDR:** Breast Cancer Digital Repository. The mammo_dp README states it is available on request from the BCDR team.

**Our data-handling choice.** We do not redistribute any of these images and do not grant any right to them; see
`DATA_REDISTRIBUTION_AUDIT.md`. Download the patch dataset yourself, or rebuild it from the original sources following
Osuala et al.

### Patient identifiers

| Dataset | Source of the ID | Reliability |
|---|---|---|
| CBIS-DDSM | The public `P_xxxxx` identifier in each file name | Reliable |
| BCDR | Taken from the `patientbcdr__<n>` file-name prefix | Only 127 of 394 could be confirmed against upstream metadata, so BCDR patient-bootstrap intervals assume this grouping is correct |

## Synthetic data

| Pool | Used for | Source | In this repository |
|---|---|---|---|
| CC-NET (3,000 images: 1,500 benign / 1,500 malignant, 256×256) | Real+CC-NET classifiers, FID / FRDv1 | Generated by us | **No** (see docs/limitations.md) |
| MCGAN (3,000 images: 1,500 / 1,500, 128×128) | FID / FRDv1 only | Published by Osuala et al. in mammo_dp `extension/synthetic_data/cbis-ddsm/c-dcgan/` | **No.** Only a file-name/hash mapping (`configs/experiments/mcgan_pool_name_mapping.csv`) |

**Arranging the MCGAN images.** `python scripts/prepare_data.py organize-mcgan --source <c-dcgan dir> --target <dir>`
arranges them exactly as used here and verifies every SHA-256.

**Synthetic images are not anonymous.** They were produced by generators trained without differential privacy on
patient images, so they should not be treated as anonymous or free of privacy risk.

## EUCanImage

**EUCanImage** data was used in other parts of the wider project. It is **not** used by any experiment in this repository,
and nothing derived from it is included.
