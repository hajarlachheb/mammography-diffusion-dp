# Data redistribution audit

**Scope:** this public repository candidate.
**Principle:** nothing derived at image level from a clinical dataset is included unless redistribution is clearly
permitted. Where terms could not be verified, the item is excluded.

## Datasets and derived artifacts

| Item | Source / terms | Included? | Reason |
|---|---|---|---|
| CBIS-DDSM images and patches | TCIA, Curated Breast Imaging Subset of DDSM. TCIA lists a Creative Commons Attribution license for this collection; **the authors should confirm the current terms on the TCIA page before release** | **No** | Users obtain the data from TCIA, or the patch set from mammo_dp. Avoids redistributing clinical images |
| BCDR images and patches | Breast Cancer Digital Repository, available on request (per the mammo_dp README). Redistribution terms not verified | **No** | Treated as non-redistributable |
| EUCanImage | Consortium data under access agreements | **No** | Not used by any experiment in this repository. No EUCanImage-derived file, figure, number or manifest is included |
| mammo_dp `dataset16062024/` patch splits | Published in the mammo_dp repository (Apache-2.0 code license). The README states no separate data license | **No** | We point users to it; we do not copy it |
| Published MCGAN images (3,000) | mammo_dp `extension/synthetic_data/cbis-ddsm/c-dcgan/` | **No** | Only file names and SHA-1 / SHA-256 hashes (`configs/experiments/mcgan_pool_name_mapping.csv`), needed to reproduce the FID / FRD subsampling |
| CC-NET synthetic pool (3,000) | Generated by us with a generator trained **without DP** on CBIS-DDSM training images | **No** | Derived from patient images by a non-private model; memorisation cannot be excluded. Needs an explicit author / institutional decision |
| CC-NET generator weights | Ours, trained on CBIS-DDSM (non-DP) | **No** | Same reason; also large (10 GB). The SD-2.1 base weights carry their own license |
| Classifier checkpoints (21) | Ours, DP-SGD on CBIS-DDSM | **No** | Not needed for the published claims. SHA-256 of each is listed in `results/verified_summary/run_acceptance.csv` so released copies could be verified later |
| Per-image predictions | Ours | **No** | Contain dataset file names and patient identifiers (CBIS `P_xxxxx`, BCDR) |
| Aggregate metrics (CSV) | Ours | **Yes** | Means, SDs and CIs over runs. No image-level or patient-level rows |
| Publication figures | Ours | **Yes (5)** | Plots and schematic only; no image content |
| Manuscript Fig. 2 / Fig. S1 (example patches) | — | **No** | They contain real CBIS-DDSM / BCDR patches and synthetic patches |

## Identifiers present in the repository

- **No real patient identifiers.**
- **Test fixtures** use invented, out-of-range IDs (`P_9000x`, `patientbcdr__80x`), labelled as test fixtures.
- **Documentation** mentions only the identifier *formats*.

## Checks performed

- **Content scan** of every file (see `SECURITY_AUDIT.md`): magic bytes for PNG / JPEG / DICOM / pickle / zip, and
  regular expressions for patient-ID patterns.
- **`.gitignore`:** excludes images (except the publication figures), DICOM / NIfTI, data folders, weights, run outputs
  and logs. Tested with `git check-ignore` on sample paths.
